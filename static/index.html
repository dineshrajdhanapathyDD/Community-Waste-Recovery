Welcome back

Enter your email and we'll send you a one-time code. Identities represent organizations (donor, recipient, coordinator) — the agent filters the tools each org can see.

How this works

Every message you send follows this path through AWS:

  1. Browser (this SPA) — you sign in and type a question.
  2. Amazon Cognito — you enter your email, Cognito emails a one-time code, and verifying it returns a JWT access token that identifies your organization.
  3. AgentCore Runtime — the SPA calls InvokeAgentRuntime over HTTPS with the JWT as a Bearer token. A custom JWT authorizer validates it.
  4. Strands agent (agent.py) — runs Claude on Amazon Bedrock. It has no built-in knowledge; it only relays tool results.
  5. AgentCore Gateway (MCP) — the agent opens only the tool gateways your org is allowed to use.
  6. Amazon Verified Permissions — filters which tools your identity can access, per request.
  7. Backend tools — Lambda (guidelines, SigV4) and API-Gateway targets (surplus, catalog, needs, pantry, volunteers, vehicles) via OAuth2 minted by AgentCore Identity.
